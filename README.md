# SmartCart

AI-powered MERN e-commerce platform with intelligent shopping features.

## Technology Stack
- Frontend: React
- Backend: Node.js and Express.js
- Database: MongoDB
- AI/ML: Python and machine learning

## Key Features
1. AI Shopping Assistant
2. Price History and Buy Timing
3. Product Trust Score
4. Local Seller Marketplace
5. Smart Product Comparison
6. Budget-Controlled Shopping
7. Search by Image
